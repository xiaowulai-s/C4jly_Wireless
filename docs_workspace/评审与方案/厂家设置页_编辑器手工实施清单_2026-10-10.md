# 厂家设置页 —— 改屏实施方案（编辑器手工版）

> 背景：脚本产出的 `C4F7N_v9.HMI` 编辑器**报「项目文件已受损」**，工具链自检（`verify_all_pages` `ok=6 bad=0`、`check-page` 全过）却查不出问题。
> 结论：**新增页这一步 hmipack 路线走不通**，改用编辑器手工建页 —— 这也正是编辑器原生支持的路径。
> 基线：`C4F7N_v8.HMI`（md5 `acc337c478f015e7be80c64fb75d438f`）**请先用它确认能正常打开**。

---

## 一、开工前

1. **关闭编辑器**（占着文件会 EBUSY）
2. `C4F7N_v8.HMI` 复制一份 → **`C4F7N_v9.HMI`**（**不要覆盖 v8**，它是当前生产基线）
3. 用编辑器打开 **`C4F7N_v9.HMI`**
4. 打开后**立刻另存为** `C4F7N_v9.HMI`（编辑器打开时会重存归一化，这是正常的）

⚠️ **第 3 步如果就打不开，说明 v8 本身在你的编辑器版本下有问题**，那要先解决这个，别往下做。

---

## 二、新建厂家页

### 2.1 建页

菜单 `页面` → `新建页面`，在**设置页之后**添加（这决定页 ID）：

| 项 | 值 |
|---|---|
| 页面名称 | `厂家设置` |
| 背景色(bco) | `6438` |
| 宽 × 高 | `1024 × 600` |

⚠️ **必须加在设置页之后** ⇒ 新页页 ID = **5**（主页0 / 历史1 / 设置2 / 初始化3 / keybdB4）。

建完先记下实际页 ID，固件要用。

### 2.2 复制页头（从主页 `4.pa` 复制）

在**主页**上框选并复制下面这些控件，粘贴到厂家页，**坐标保持不变**：

| 对象 | 类型 | x / y / w / h | 备注 |
|---|---|---|---|
| `p0t` | 文本 | 75 / 16 / 360 / 35 | 标题，保持「C4F7N便携式检漏仪」 |
| `dvr` | 文本 | 0 / 64 / 1024 / 2 | 报警色带，`bco=12777` |
| `lg` | 图片 | 14 / 6 / 52 / 52 | `pic=10` |
| `pc0b` `pc0` `pc0d` | 图片/文本/图片 | 626/18 · 650/18 · 638/18 | 探头胶囊（**三件套**）|
| `pc1b` `pc1` `pc1d` | 图片/文本/图片 | 768/18 · 792/18 · 780/18 | 泵胶囊 |
| `pc2b` `pc2` `pc2d` | 图片/文本/图片 | 890/18 · 914/18 · 902/18 | 电量胶囊 |
| `rY` `sY1` | 数字/文本 | 730/50 · 780/50 | 年 |
| `rM` `sY2` | 数字/文本 | 800/50 · 830/50 | 月 |
| `rD` `sSp` | 数字/文本 | 850/50 · 880/50 | 日 |
| `rH` `sCl` | 数字/文本 | 890/50 · 920/50 | 时 |
| `rMi` `sCl2` | 数字/文本 | 930/50 · 960/50 | 分 |
| `rsec` | 数字 | 970/50 | 秒 |

**★ 粘贴后必须逐个改名**，加 `_f` 后缀（避开与主页同名）：

```
p0t→p0t_f    dvr→dvr_f    lg→lg_f
pc0→pc0_f    pc0b→pc0b_f    pc0d→pc0d_f
pc1→pc1_f    pc1b→pc1b_f    pc1d→pc1d_f
pc2→pc2_f    pc2b→pc2b_f    pc2d→pc2d_f
rY→rY_f   sY1→sY1_f   rM→rM_f   sY2→sY2_f
rD→rD_f   sSp→sSp_f   rH→rH_f   sCl→sCl_f
rMi→rMi_f   sCl2→sCl2_f   rsec→rsec_f
```

★ `pc0d`/`pc1d`/`pc2d` 是**状态圆点**，必须一起复制 —— 漏了会变成「有文字无状态点」。

### 2.3 页头 load 事件（改掉复制来的）

主页页对象的 `load` 里写的是 `rY.val=rtc0` 等，**那是主页的时间控件名**，在新页会找不到。改成：

```tjc
codesload-7
rY_f.val=rtc0
rM_f.val=rtc1
rD_f.val=rtc2
rH_f.val=rtc3
rMi_f.val=rtc4
rsec_f.val=rtc5
codesloadend-0
```

★ 厂家页**不需要** `tm0.en=1`（那个定时器在设置页才有）。

### 3.3 加「返回设置」按钮

新建一个按钮，`type=98`：

| 项 | 值 |
|---|---|
| 名称 | `bk` |

**弹起事件**：

```tjc

```

★ `2` 是设置页的页 ID（若你插入新页后页 ID 变了，改成实际值）。

## 四、改设置页

### 4.1 删掉 8 个对象

`czl` `csl` `cfl` `c0` `c1` `cf` `cst_s1` `crs_s1` —— 全部删除。

⚠️ 删完设置页的标定区会空出一块（x=45~435, y=410~490），**这是预期的**，不用管。

### 4.2 `fw` 加长按进入厂家页

**做法 A（推荐，无需定时器）**：设置页 `fw` 的**弹起事件**：

```tjc
page 5
```

但这会变成**单击就进** —— 如果要长按，用做法 B。

**做法 B（真长按，需定时器）**：

1. 设置页**新建一个定时器** `tmr1`：`tim=5000`（ms）、`en=0`
2. `tmr1` 的**定时事件**：

```tjc
codesTimer-2
tmr1.en=0
page 5
```

3. `fw` 的**按下事件**：

```tjc
codesdown-1
tmr1.en=1
```

4. `fw` 的**弹起事件**：

```tjc
codesup-1
tmr1.en=0
```

★ 逻辑：按住 → 定时器启动 → 满 5 秒触发进页；提前松手 → 定时器被关掉，永不触发。

⚠️ **`codesXX-N` 的 N 必须等于该事件下的脚本行数**，写错会让事件**静默不执行**（按钮点了没反应）。上面给的行数与声明已对齐。

## 六、固件改动（屏验证通过后我做，约 25 行）

1. `c4f7n_hmi_protocol.h` 新增宏：

```c
#define OBJ_PROBE_CHIP_F  "pc0_f"
#define OBJ_PUMP_CHIP_F   "pc1_f"
#define OBJ_PROBE_DOT_F   "pc0d_f"
#define OBJ_PUMP_DOT_F    "pc1d_f"
#define OBJ_CAL_ST_F      "cst_f"
#define OBJ_CAL_RS_F      "crs_f"
```

2. **两处** `sfx` 表加一行（`main.c:551` 与 `:658` 附近）：

```c
else if (g_page_now == 5u) sfx = "_f";
```

3. `hmi_on_page_enter(p)` 收到厂家页时：`g_page_now = 5; g_full_dirty = 1;`

⚠️ **`pc2_f`（电量胶囊）不能照搬 `tjc_set_bat()` 的「无条件推 4 条」做法** ——
那招只对「存在无条件推送路径」的对象有效，而 `pc2` 走 `sfx` 门控，照搬会让该页不更新。

## 七、如果编辑器手工建页也很麻烦

那就换个思路：**厂家页的按钮不改对象名、不搬页面**，改为在**设置页把 8 个对象 `vis` 隐藏**（`vis fw,0`），长按时再 `vis fw,1` 并把页面 `load` 里的跳转放开。

这样改动最小、风险最低，但「隐藏的元素仍可被 `click` 触发」—— 需要配合隐藏后**禁用触摸**（`tsw c0,0`）。是否走这条，你定。
