## 1. 数据结构变更（`param_t`）

```c
#define PARAM_MAGIC     0xC4F74A55u
#define PARAM_VERSION   3u            /* 2 -> 3 */

typedef struct {
  uint32_t magic;      uint32_t version;
  int32_t  cal_k;      int32_t  cal_b;
  int32_t  cal_raw0;   /* 新增: 零点标定时的原始读数(两点标定的下点); 0x7FFFFFFF = 未做过零点 */
  uint32_t cal_ts;     /* 新增: 标定时刻 epoch(秒); 0 = 未标定 */
  uint32_t hist_base;  /* 新增: 历史区起始代数(逻辑清空的起算点) */
  uint16_t thr_hi;     uint16_t thr_lo;
  uint8_t  buzzer_en;  uint8_t  cal_valid;
  uint16_t _rsv;       /* 对齐保留 */
  uint32_t crc;
} param_t;             /* 28B -> 40B */
```

- **删除 `unit_mode`**（残留点 3 决定）：它写了从来没被读，属死字段；将来真要做单位切换再加回
- **版本迁移**：`version != 3` → 视为无效 → 回默认值。**代价：升级后需重新标定一次**（阈值也回 500/100）
- **`param_factory()` 保留 `hist_base` 现值**（残留点 1 决定）：恢复出厂只重置标定/阈值/蜂鸣器，
  **不撤销"清空历史"**；`cal_raw0` 与 `cal_ts` 回哨兵/0（即"未标定"）
- **追加式写**：每槽 40B → `4096/40 = 102` 槽。**槽内无独立序号**，靠"从后往前找第一条 CRC 有效记录"定位最新
  - 槽地址：`PARAM_FLASH_ADDR + slot * 40`，`slot = 0..101`
  - 写入：找第一个全 `0xFF` 的槽直接 page program；写满则擦扇区后从 slot 0 重新开始
  - 读回：从 slot 101 倒序找 CRC 有效者

### 2.3 `Core/Src/main.c`（改动最大）

**A. 三个标定回调改为"置标志 + 主循环执行"**

```c
/* 新增: 标定请求标志(ISR 只置位) */
enum { CAL_REQ_NONE=0, CAL_REQ_ZERO, CAL_REQ_SPAN, CAL_REQ_FAC };
static volatile uint8_t g_cal_req = 0;

void hmi_on_cal_zero(void) { g_cal_req = CAL_REQ_ZERO; }   /* ISR: 仅置标志 */
void hmi_on_cal_span(void) { g_cal_req = CAL_REQ_SPAN; }
void hmi_on_cal_factory(void){ g_cal_req = CAL_REQ_FAC; }

static void cal_poll(void) {           /* 主循环调用(在 app_refresh 之前) */
  uint8_t r = g_cal_req; if (!r) return;
  g_cal_req = 0;
  switch (r) {
    case CAL_REQ_ZERO: cal_do_zero(); break;
    case CAL_REQ_SPAN: cal_do_span(); break;
    case CAL_REQ_FAC:  cal_do_factory(); break;   /* 内含 HAL_Delay + NVIC_SystemReset */
  }
}
```

**B. 前置校验（统一入口）**

```c
/* 返回 0=可标定; 否则返回失败原因枚举 */
static int cal_precheck(void) {
  if (!sensor_online())                       return CAL_E_OFFLINE;   /* 探头未连接 */
  if ((HAL_GetTick() - g_boot_ms) < CAL_WARM_MS) return CAL_E_WARMUP; /* 预热<120s */
  return 0;
}
#define CAL_WARM_MS  120000u   /* 对齐 sensor.h「预热≥2min」 */
```

**C. 零点标定（改为"记录下点"）**

```
precheck -> 失败则写结果并 return
ppm = sensor_read_ppm(); if (ppm >= 20) -> CAL_E_DIRTY
raw = sensor_read_raw();
PP.cal_raw0 = (int32_t)raw;          /* 只记下点, 暂不算 k/b */
PP.cal_ts   = rtc_wall_seconds();    /* 时间戳(若 RTC 未就绪则 0) */
PP.cal_valid = 1;
param_save; -> 结果「执行」
```
> ⚠️ 仅做零点时 `cal_k/cal_b` 保持原值（零点标定**不单独生效**，需与量程配合成两点）。

**D. 量程标定（两点联合求解）**

```
precheck -> 失败则写结果并 return
if (PP.cal_raw0 == 0x7FFFFFFF) -> CAL_E_NOZERO（"请先做零点标定"）
ppm 必须在 span*0.9 ~ span*1.1 -> 否则 CAL_E_WINDOW
raw1 = sensor_read_raw(); if (raw1 <= 0) -> CAL_E_BADRAW
与 raw0 需有足够间距: (raw1 - raw0) 太小 -> CAL_E_TOOCLOSE  (阈值待定, 建议 >= 50)
k = (int64_t)span * 1000 / (raw1 - raw0);           /* 两点解斜率 */
b = -(int64_t)raw0 * k / 1000;                      /* 由零点定点解截距 */
钳位 k ∈ [SENSOR_CAL_K_MIN, MAX]; 越界 -> CAL_E_KCLAMP
PP.cal_k=k; PP.cal_b=b; PP.cal_ts=rtc_wall_seconds();
param_save; sensor_set_cal(k,b); -> 结果「执行」
```

> 数学核对：`ppm(raw0) = raw0·k/1000 + b = raw0·k/1000 − raw0·k/1000 = 0` ✓
> `ppm(raw1) = raw1·k/1000 + b = (raw1−raw0)·k/1000 = span` ✓　**两点都精确**

**E. 结果文案（统一 helper）**

```c
static void cal_report(uint8_t btn, uint8_t ok, uint8_t reason);
/* btn: c0/c1/cf;  按钮写 3 字短词, 右栏 calrs 写完整原因 */
```
| 原因码 | 按钮短词 | 右栏详细原因（示例） |
|---|---|---|
| OK | 执行 | 零点标定完成 或 量程标定完成 |
| OFFLINE | 未接通 | 标定失败：探头未连接 |
| WARMUP | 预热中 | 标定失败：需开机 120 秒后（示数稳定） |
| DIRTY | 浓度高 | 零点失败：当前 35ppm，需 <20ppm |
| WINDOW | 超窗口 | 量程失败：当前 850ppm，需 900~1100ppm |
| BADRAW | 非法值 | 量程失败：原始读数为 0，检查探头 |
| NOZERO | 无零点 | 量程失败：请先做零点标定 |
| TOOCLOSE | 点太近 | 量程失败：与零点读数差太小 |

**F. 标定状态上报屏端（进设置页时）**
```
app_apply_threshold() 处顺带(或 hmi_on_page_enter p==1 分支)：
  cal_ts==0  -> calst.txt="标定：未标定"                    (灰/默认色)
  未超期     -> calst.txt="标定：YYYY-MM-DD"                (默认色)
  超期(>180天)-> calst.txt="标定：YYYY-MM-DD 已超期"        (橙色 tjc_set_pco)
```

**G. 恢复出厂（`cal_do_factory`，主循环内执行）**
```
param_factory(&PP,1)      -> 新结构默认值(cal_raw0=哨兵; cal_ts=0; hist_base 保留, 见 §6-1)
g_thr_hi/lo 同步; sensor_set_cal; app_apply_threshold();
HAL_Delay(120)            -> 现在在主循环里, 不再死锁
NVIC_SystemReset();
```
> **历史记录不受影响** ✓ —— 「恢复出厂」与「清空历史」是两个独立动作。

## 7. 风险提示

| 改动量 | 固件 4 个文件 + 屏端 3 个页/文件；属较大改动，建议一次性编译+烧录后统一回归 |
