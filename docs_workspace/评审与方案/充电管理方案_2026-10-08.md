## 一、定稿结论（可直接执行）

| 项            | 定稿值                                                            | 性质               |
| ------------ | -------------------------------------------------------------- | ---------------- |
| **适配器**      | **19V / 2A**（≥40W）                                             | 换掉现 16.8V        |
| **充电拓扑**     | `19V → D2(SS34) → 【4S Buck CC/CV 模块】→ 电池`，**SS34 移到 Buck 输入侧** | 关键改动             |
| **CV 目标电压**  | **16.7V**                                                      | ★ **保守交集**（见 §三） |
| **CC 充电电流**  | **1.5A**（0.19C，厂商标准 0.2C=1.56A）                                | 保守取整             |
| **NTC 温度保护** | **必需**（电池充电温度 0~45°C）                                          | 不可省              |
| **状态回显**     | `CHRG` + `STDBY` 两路 → MCU 2 个 GPIO                             | 新增               |
| 电池本体         | **不需加保护板**（自带 PCM）                                             | 用户确认             |

### 为什么 CV 取 16.7V 而不是 16.8V

公开资料对 4S PCM 过充点有两种说法：**16.8V±0.05V**（fpbattery 同规格）vs **4.25V×4 = 17.0V**（cbea 同规格）。取**两者的交集 16.7V**：

- 若实际是 16.8V → 16.7V 留 0.1V 余量，**不触发 PCM，能正常终止**
- 若实际是 17.0V → 16.7V 更安全，且**容量几乎无损**（差 0.6%，<1%）

⚠️ **若将来拿到规格书且确认为 17.0V，可把 CV 提到 16.85V**（多 0.9% 容量），但没必要为这点容量冒险。

### 充电时间预估

`7800mAh ÷ 1500mAh ≈ 5.2h`（CC 阶段）+ CV 阶段约 0.5~1h ⇒ **满充约 6 小时**。

> 若嫌慢可把 CC 提到 2A（0.26C，厂商允许 0.5C 内），但会缩短寿命、发热更大，且需换 19V/2.5A 适配器。**建议先用 1.5A 验证，后续按需调整**（模块多为电阻设定电流）。

## 二、选型：买成品模块（路线 A，样机最快）

### 搜索关键词

**"4S 锂电池充电板 16.8V 降压 CC/CV 带保护 10k NTC"** 或 **"4S 锂电充电器 19V输入 NTC 状态输出"**

### ★ 验收清单（买之前逐条问卖家 / 看资料）

| # | 要求                                         | 必要度  |
| - | ------------------------------------------ | ---- |
| 1 | **明确支持 4S / 输出 16.8V**（不是 1S/2S 板）         | ★必需  |
| 2 | **CC + CV 两阶段**（最好含涓流预充）                   | ★必需  |
| 3 | **有 NTC 接口**（10kΩ，B 值标注清楚）                 | ★必需  |
| 4 | **CV 可调 / 明确标称值**（要求 ≤16.75V）              | ★必需  |
| 5 | 充电状态输出 2 路（`CHRG` 充电中 / `STDBY` 充满）→ 接 MCU | 强烈建议 |
| 6 | 输入耐压 ≥ 20V                                 | ★必需  |
| 7 | CC 电流可设 1.5A（或给电阻位说明）                      | 建议   |
| 8 | 具备防反接 / 输出短路保护                             | 建议   |

**预期成本**：模块 ¥15~~40 · NTC 探头 ¥2 · 19V/2A 适配器 ¥12~~20

### 若走自研（路线 B，量产前再做）

优先复核这几个型号（**下单前必须对数据手册逐条核**）：**CN3704**（如韵，7.5~~28V/5A/TSSOP16，需外接 MOSFET）、**CXLB73321**（嘉泰姆，6.8~~28V，`NCHRG`+`NSTDBY` 双路开漏，3串/4串由 SEL 选择）、IP2365（英集芯，4.5~26V，含 I²C，软件成本高）。

⚠️ 走自研还需补：原理图、PCB（功率回路布局 + 散热铜箔）、EMC 评估、样机测试矩阵。

## 三、接线表

| 端点                      | 接到                                          | 说明                             |
| ----------------------- | ------------------------------------------- | ------------------------------ |
| 19V 适配器 +               | 模块 `IN+`                                    |                                |
| 适配器 −                   | 模块 `IN−`                                    |                                |
| **原 D2(SS34) 阳极**       | 从 `CHG_IN` **改接到适配器 + 侧**（模块 `IN+` 之前）      | ★ **必须移位**：否则 0.45V 压降吃掉 CV 精度 |
| 原 D2 阴极                 | `CHG_IN`                                    |                                |
| 模块 `BAT+` / `BAT−`      | 电池 `BATTERY` 正 / 负（**经 CN1 或整机开关之后**，保持原结构） |                                |
| 电池 NTC 探头（或电池引出的 NTC 线） | 模块 `TEMP` / `NTC`                           | **无 NTC 则外挂 10kΩ 探头**          |
| 模块 `CHRG`（充电中，通常开漏）     | MCU GPIO（需 10kΩ 上拉到 3.3V）                   |                                |
| 模块 `STDBY`（充满，通常开漏）     | MCU GPIO（需 10kΩ 上拉到 3.3V）                   |                                |
| 模块 `CE`/`EN`（如有）        | 常使能或接 MCU 自行控制                              |                                |

⚠️ **两个 GPIO 的具体引脚待定** —— 需避开 PB10/PB11（屏 USART3）、PB1（电池 ADC）、PC10/PC11（传感器 USART4）、PA9/PA10（预留 USART1）、以及 v28 之后的泵 PWM/风扇脚。选定时与硬件改动一并确定。

⚠️ 若模块的 `CE` 悬空会停止充电 —— **务必确认使能方式**（多数模块 CE 拉高使能，或直接悬空内置上拉）。

## 四、固件侧改动（实施时另起一版 v46）

现状：**固件完全无充电状态处理**（`C4F7N_Demo/` 内搜不到任何 CHG/PG 逻辑）。

| 状态  | 判据                   | 屏端建议          |
| --- | -------------------- | ------------- |
| 未接电 | `CHRG=1` 且 `STDBY=1` | 不显示充电图标       |
| 充电中 | `CHRG=0`             | 🔴 图标 + "充电中" |
| 已充满 | `STDBY=0`            | 🟢 图标 + "已充满" |

**改动点**：

1. 新增 2 个 GPIO 输入 + 输入上拉配置
2. 新增充电状态量，**走现有镜像下发模式（变化才发，稳态 0 字节）** —— 与 L1 减量设计一致
3. 屏端 4 页顶栏加充电图标（**需在 TJC 编辑器加对象，随后跑 T-28 自检 + `verify_all_pages`**）
4. 可选：充电期间不启动泵/测量（充电时电源纹波大，避免读数不稳）

⚠️ 改动会影响 GitHub 上的 v45 基线，实施后需重新编译归档（v46）并同步变更记录。

## 五、验收（实施后必做）

| # | 项           | 判据                                                         |
| - | ----------- | ---------------------------------------------------------- |
| 1 | 空电（12.0V）接电 | 正常进入 CC，无过冲                                                |
| 2 | **CC 电流实测** | 1.5A ±10%                                                  |
| 3 | **满充电压实测**  | **16.7V**（比 PCM 阈值低 ≥0.1V）                                 |
| 4 | 终止判定        | 电流降到阈值后 `STDBY` 拉低，屏显"已充满"                                 |
| 5 | **NTC 生效**  | 加热/冷却 NTC → 充电暂停/降流、恢复                                     |
| 6 | 断电          | 充电中直接拔适配器 → 屏指示消失，系统由电池供电**不重启**                           |
| 7 | **对照旧行为**   | 新方案满充电压应比**原来的 16.35V 高约 0.35V**（SS34 压降被 Buck 补偿）⇒ 容量真实提升 |
| 8 | 温升          | 充电 1 小时，模块外壳温度 < 50℃                                       |

**第 7 项是本方案价值的直接证明** —— 若满充电压仍停在 16.35V，说明 SS34 压降没被补偿，方案没达到目的。
