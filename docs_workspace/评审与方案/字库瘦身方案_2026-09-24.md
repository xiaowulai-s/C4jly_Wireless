# 字库瘦身方案（TJC 屏端）

> 依据 `C4F7N_v7b.HMI`（53477737 B）实测生成，生成脚本 `tjc-hmi-toolkit/C4F7N/_font_plan.js`。
> 复验脚本：`_font_v7b_audit.js`（字库清单/引用/font 映射）、`_font_charset_scan.js`（固件上屏字符集）。

## 1. 结论

| | 体积 | 占比 |
|---|---|---|
| 字库合计（现状） | **43.51 MB** | 85.3% |
| 工程文件（现状） | 51.00 MB | — |
| 字库改成「指定字库」后 | **0.86 MB** | 1.7% |
| 工程文件（预计） | **8.35 MB** | −84% |

**可省 42.65 MB。** 原理：TJC 的 GB2312 字库是 **8273 字全量点阵**，
而本工程每个字库实际只用到几十个字 —— 用官方「**指定字库**」功能（字库制作 → 范围选「指定字符」）
只生成用得上的字，**显示逐像素不变**。

> 官方数据佐证（wiki QA8）：字高 56 / GB2312 全字库 = 2,683,293 B；同一参数**指定字库 = 3,033 B**。

### 2.1 可无条件删除（零引用）

- `1.zi`（GB2312/64，4.76 MB）—— `font=1` **零引用**。
- `2.zi`（GB2312/16，0.35 MB）—— `font=2` **零引用**，且与 `0.zi` **逐字节完全相同**（md5 一致）。

### 2.2 三个「一个控件吃掉一个全量字库」的浪费

| 字库 | 现状 | 唯一使用者 | 实际需要 |
|---|---|---|---|
| `4.zi` | 19.60 MB | `主页/cc`（数字控件，浓度大字） | 数字 + `.` `-` = 16 字符 |
| `6.zi` | 4.64 MB | `主页/pu`（文本，内容 = `ppm`） | ` ` `p` `m` = 3 字符 |
| `7.zi` | 10.84 MB | `初始化/prewarm_i`（`预热中，请稍候`） | 8 字符 |

### 2.3 不要动

- `9.zi` / `10.zi`：**键盘页自带**的 ASCII 字库，仅 2.5 KB / 3.5 KB。编辑器重建键盘页时会重新生成，删了大概率又被加回来。

## 4. 操作步骤（必须在 USART HMI 编辑器里做）

> ⚠️ **不要对 `.HMI` 做文件级手术**：删/加字库会让编辑器重排资源表，`font=` 是按**资源表序号**引用的，
> 只有编辑器自己重排才会同步更新控件的 `font` 属性。

0. **先备份** `C4F7N_v7b.HMI`（或先另存为 `C4F7N_v8.HMI`），改动都在副本上做。
1. **删零引用项**：双击资源里的 `1.zi`、`2.zi` → 删除。这一步无风险，先拿到 5.11 MB。
2. **做新字库**：`工具 → 字库制作` → 字体/字高与旧的一致（见 §3 标题） → **范围选「指定字符」** → 粘贴 §3 的字符 → 生成，保存到工程素材目录 → 加入工程。
3. **改指向**：把原控件的 `font` 属性改成新字库（§3 各节列了使用者；`cc`/`pu`/`prewarm_i` 各只有一个）。
4. **删旧字库**：确认没有控件还引用旧的了（用 `_font_v7b_audit.js` 复验）→ 再删旧的 `4.zi`/`6.zi`/`7.zi`。
5. **保存 → 另存为 `C4F7N_v8.HMI`**（这一步是必须的：编辑器会把工程归一化，必须让它自己写一遍）。

### 顺序为什么不能反

先删旧字库 → 资源表重排 → 所有 `font=N` 整体前移 → 控件指向别的字库，**全屏错字**。
所以规则是：**先建新的、先改指向、最后才删旧的**。每步之间跑一次审计脚本确认。

## 6. 备注

- 估算方法：`字库字节数 ÷ 8273 字` 得每字平均字节，乘所需字数 → 属**估算**，实际以生成结果为准。
- `.zi` 头部格式（实测）：字节 0-3 魔数 `04 FF 00 0A`；**字节 4 = 编码（1=ASCII / 2=GB2312）**；
  字节 5 = 全字库标志；字节 7 = 字高(px)；字节 12-13 = 字符数（ASCII=95 / GB2312=8273）。
  > 勘误：早期文档写「字节 4-5 = 编码」，实际是 **字节 4**；字节 5 恒为 1(GB2312)/0(ASCII)。
- `font=` 的 id = 字库在 `main.HMI` 资源表中的**序号**，**不是** `.pa`/`.zi` 文件名里的数字。
