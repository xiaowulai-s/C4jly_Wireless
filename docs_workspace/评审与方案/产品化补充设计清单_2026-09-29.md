# 产品化补充设计清单（路线图）

> 2026-09-29 · 基于固件 v35 / 屏 v7b（`1c4af41e`）现状。**全部暂不实施**，供排期决策。
> 编号体系：**R1~R22**（Roadmap；固件 R1~R10 / 硬件 R11~R17 / 合规 R18~R22），与开发进度表 §九 一致，避免与功能矩阵 F-xx、任务 T-xx 混淆。
> 已在进度表排队的（T-07 报警闩锁、T-16 滤波、T-11 发送健壮性）直接引用不重复展开。

## 0. 现状基线（已具备）

测量显示 / 双阈值报警 + 喇叭 / 历史记录与分页 / 真两点标定 + 补偿显示（v34）/ 低电三级提示（v30）/ POST + Flash 禁写（v26/27）/ 泵 PWM 调速（v28）/ 串口减压 + 115200（v24/25）/ 电量计量链路（v29~v33）/ 参数与标定数据持久化。

## 1. 固件类（无需改板，现有硬件即可做）

| # | 功能 | 价值 | 工作量 |
|---|---|---|---|
| R1 | **报警静音时限**：静音改为 1~5 分钟自动恢复（现为静音到报警解除） | 防"永久静音漏报"—— 商业气体检测仪标配 | 小 |
| R2 | **按键锁定**：长按 3s 锁定/解锁全部按键 | 便携现场设备防误触标配 | 小 |
| R3 | **报警事件记录**：历史只存浓度点，不存"何时报警" —— 闩锁（T-07）落地后必须配套（报警开始/结束/峰值入 Flash） | 事后追溯"漏过的泄漏" | 中 |
| R4 | **传感器寿命/使用时长累计**：累计工作小时 + 标定次数入 Flash，寿命到期提醒 | NDIR 光源有寿命；售后备件销售依据 | 中 |
| R5 | **故障日志（黑匣子）**：复位原因、掉电前状态、异常事件环形队列入 Flash | 售后诊断不用"猜" | 中 |
| R6 | **SN/硬件版本/标气类型页**：关于页显示出厂序列号与硬件版本（SN 烧写到 Flash 保留区） | 售后/追溯最小集 | 小 |
| R7 | **背光自动策略**：无操作 N 分钟降背光→息屏，任意触摸唤醒 | 功耗测试的直接收益（待机时长翻倍级）；`dim` 系统变量已具备 | 小 |
| R8 | **标定到期策略可配置**：到期"仅提示"（现状）/ "锁定测量仅可看历史" 两档 | 计量级客户的合规要求 | 小 |
| R9 | **STEL/TWA**（15min 短时接触 / 8h 加权平均） | 职业健康场景标配；⚠️ C₄F₇N 暂无国标职业限值，是否需要取决于目标客户（如电力行业内部标准） | 中 |
| R10 | **零点自动跟踪**：长时间运行中缓慢漂移自动微修（快速变化仍报警） | 计量型产品常见；须与手动标定互斥，防"把真泄漏当漂移吃掉" | 中 |

## 2. 硬件配套类（需改板/改线，固件同步）

| # | 功能 | 现状差距 | 说明 |
|---|---|---|---|
| R11 | **充电管理**（最大短板） | 现为 CHG_5V 经 SS34 直充，无管理 IC、无温度监控 | 4S 需带平衡的充电方案（或改 2S+升压）+ NTC + 充电指示灯 + 屏显"充电中/已充满"；否则电池寿命与安全都是隐患 |
| R12 | **EN 自动关机线** | EN 未接 MCU（T-09 三级现为持续催促） | 一条线升级"12.6V 自动保存+关机"，低电保护才算闭环 |
| R13 | **报警灯/振动** | 仅喇叭 | 现场嘈杂环境声光双报是标配；高亮 LED（+振动马达可选） |
| R14 | **USB Type-C（充电+数据）** | 仅 5V 充电口 | 复用为 CDC 虚拟串口：数据导出 + **固件升级通道** + PC 标定软件 |
| R15 | **bootloader/升级通道** | 无 —— 固件更新必须拆机接 SWD | 商业产品售后硬需求（与 R14 配套：串口 Ymodem 或 USB DFU） |
| R16 | 蓝牙模块（可选） | 无 | 手机 App 显示/导出；检漏仪常见配置，视市场定 |
| R17 | RS485 端子（可选） | 原理图已画 PE3485 但未接 | Modbus RTU 接入客户系统；工业客户会要 |

## 3. 合规与制造类（商业化的硬门槛）

| # | 项 | 说明 |
|---|---|---|
| R18 | **出厂标定工装与流程** | 自动通标气 + PC 判定合格 + 写 SN/标定记录；产线没有这套就无法批量交付 |
| R19 | **计量认证（CPA 型式批准）** | 测量类产品上市法规要求；周期长（半年+），尽早启动 |
| R20 | **防爆认证（Ex）** | 若目标场景含可燃气体环境（电气柜内检测需评估）；本安设计影响整机架构，**越晚决定代价越大** |
| R21 | EMC / RoHS / CE | 常规认证 |
| R22 | 说明书/标签/包装 | 警示语、标气要求、维护周期声明 |

## 4. 优先级建议

| 优先级 | 项 | 理由 |
|---|---|---|
| **P0 不补无法交付** | R11 充电管理 · R15 升级通道 · R6 SN/版本 · T-07 报警闩锁 · R1 静音时限 | 安全部件缺失 / 售后不可运维 / 漏报责任 |
| **P1 竞争力** | T-16 滤波 · R2 按键锁 · R3 报警事件 · R4 寿命累计 · R7 背光策略 · R12 自动关机 · R14 USB · R18 标定工装 | 口碑与运维成本 |
| **P2 市场细分再定** | R9 STEL/TWA · R10 零点跟踪 · R16 蓝牙 · R17 Modbus · R19/R20 认证启动时机 | 看目标客户（电力/工业/出口） |

## 5. 与现有进度表衔接

- T-07（闩锁）+ R3（事件记录）应**作为一个整体设计**（闩锁产生事件，事件要落盘）
- T-16（滤波）参数应与 R11 之后的工况（泵定速）联合标定
- 功耗测试（`docs/测试/`）的 S1/S2 数据直接决定 R7 背光策略的收益量化
