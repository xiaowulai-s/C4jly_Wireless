## 四、三个必须注意的点

1. **改坐标必须同步 `endx`/`endy`**
   编辑器里改完 `x/y/w/h` 后，`endx/endy` 通常会自动跟着变；如果没有，手动核对：
   ```
   cbv : endx=244  endy=459
   cb  : endx=399  endy=459
   cbv2: endx=709  endy=459
   ckv : endx=244  endy=509
   ck  : endx=399  endy=509
   ckv2: endx=709  endy=509
   ```
   这两个字段是**实际命中边界**，不同步则「点了没反应」且**不报任何错**。

2. **确认 6 个新对象的前后层级**在最后（不要盖住 `crs_f` 之类）。
   `crs_f` 在 y=360，新控件在 y=420 以下，不重叠，但按钮别拖到 y>560（超屏高 600）。

3. **页面 ID 不要变**。厂家页当前是 ID 5，加控件不影响。
   但如果你在编辑器里顺手增删了页面，**告诉我** —— 固件的页号映射依赖页面顺序。

## 六、预期效果

进厂家页（设置页长按 Logo 5 秒进入）后：

```
零点补偿b   -100   ppm
增益补偿k   92     %
[校B] [校K]
```

点「校B」→ 数值框调起键盘 → 输入数字 → 确定 → 固件回读并落盘，
下方 `crs_f` 显示「b 已设为 XX ppm (生效)」。

`k` 的显示是**百分比**：`cal_k=923` → 屏上显示 `92`。
若新 `k` 与旧值差超过 20%，会先显示
「k 将由 100% 改为 80%(20%), 3秒内再按校K确认」——**此时再按一次「校K」才生效**（这是保护，防止误输入把读数搞坏）。
