### 0.5 一个技术发现（值得记住）

**Node 子进程 spawn `git` 会返回 `EBUSY`** —— 直接 spawn 与 `shell:true` 都一样：

```js
spawnSync('git', ['--version'])              // status=null, error.code='EBUSY'
spawnSync('git --version', { shell: true })  // 同样 EBUSY
```

后果：我首个迁移脚本用 `git ls-files --error-unmatch` 判断"文件是否入库"，**全部误判为未跟踪**，
导致 18 份文档被 `fs.renameSync`（而非 `git mv`）搬走 → git 一度显示"16 个删除 + 未跟踪目录"。
**补救**：`git add -A` 后 git 按内容相似度识别为 **16 个 rename**，历史不丢。
**教训**：涉及 git 的操作**在 Bash 里用 `git mv`**，不要在 Node 里 spawn git。
