## 一、根因

### 1. 电量胶囊 `pc2_f`

`tjc_set_bat()` 是**硬编码 4 条**的无条件推送：

```c
const char *objs[] = { OBJ_BAT_CHIP, OBJ_BAT_CHIP_P1, OBJ_BAT_CHIP_P2, OBJ_BAT_CHIP_I };
/*                    pc2         pc2_s1        pc2_s2        pc2_i        */
```

**没有 `pc2_f`** ⇒ 厂家页电量胶囊永远收不到值。

### 2. 标定状态两行 `cst_f` / `crs_f`

`cal_upload_status()` / `cal_report()` 用的是硬编码单名 `OBJ_CAL_ST="cst_s1"` /
`OBJ_CAL_RS="crs_s1"`，**没有 `_f` 分支**；
且 `cal_upload_status` 只在 `hmi_on_page_enter(p==1)`（进设置页）时置脏触发，
厂家页永远不上报。

### 3. ★★ 顺带查出：死引用

取证屏端全工程 `cst*` / `crs*` 分布，结果是：

```
2.pa 「厂家设置」 -> cst_f, crs_f          ← 仅此一处
```

**设置页的 `cst_s1` / `crs_s1` 在「标定区搬到厂家页」时就删掉了。**
⇒ `OBJ_CAL_ST` / `OBJ_CAL_RS` 现在是**死引用**，非厂家页推它纯属白费串口流量，
还会误导后来者以为设置页还有这两行。

★ 这属于「屏端改了对象名/删了对象，固件侧没跟上」，
**只有把固件宏与屏端对象名逐个对照才查得出** —— 编译期无警告、运行期无报错。

## 三、关键代码

### 3.1 `tjc_set_bat()` 改为按页选名

```c
/* [v61] 更新「当前页」顶栏电量显示 (原: 无条件推 4 页副本)
 *  改为按页选名: 只推当前页那一个 chip, 其余页 chip 不会被同步 ——
 *  但电量变化必然置 g_full_dirty 且切页时 hmi_on_page_enter 会置脏, 下轮 battery_poll
 *  仍会补推本页, 故切页后可恢复。串口流量由 4x302B 降到 1x302B。 */
void tjc_set_bat(int pct, int page) {
  char cmd[40];
  const char *obj;
  switch (page) {
    case 0:  obj = OBJ_BAT_CHIP;    break;   /* 主页     pc2    */
    case 1:  obj = OBJ_BAT_CHIP_P1; break;   /* 设置页   pc2_s1 */
    case 2:  obj = OBJ_BAT_CHIP_P2; break;   /* 历史页   pc2_s2 */
    case 5:  obj = OBJ_BAT_CHIP_F;  break;   /* 厂家页   pc2_f  */
    default: obj = OBJ_BAT_CHIP_I;  break;   /* 初始化页 pc2_i  */
  }
  HMI_CMD_SET_BAT(obj, pct);
  tjc_send_raw(cmd);
}
```
