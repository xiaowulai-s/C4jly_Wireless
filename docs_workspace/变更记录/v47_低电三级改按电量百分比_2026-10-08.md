# v47 变更与验证记录：低电三级改按电量百分比触发（方案 A）

> 2026-10-08。屏基线**未变**：`C4F7N_v8.HMI`（md5 `ad68fbd6`）—— 本批**屏端零改动**。
> 上序：v46 电量曲线改分段查表（`v46_电量曲线改分段查表_2026-10-08.md`）。

## 1. 触发：v46 修好显示后暴露的三级阈值错位

v46 把百分比换成查表后，**仍按真实电压判定的三级阈值**折算过来变成：

| 档 | 旧电压阈值 | → 查表显示 | 屏上表现 |
|---|---|---|---|
| `lv 1` | ≤13.5V | **6%** | 橙「电量低请充电」 |
| `lv 2` | ≤13.0V | **1%** | 红「电量低请更换电池」 |
| `lv 3` | ≤12.6V | **0%** | 红（同文案，EN 未接线无自动断电） |

**问题**：后两档挤在 1% / 0%，「请更换电池」出现在已经没电的时候 → **失去提前预警意义**。

**用户裁定**：按**方案 A** 实施 —— 改按**电量百分比**触发。

## 3. 验证证据

### 3.1 编译

| 项 | 结果 |
|---|---|
| 编译 | **0 Error / 0 Warning** |
| Code | 40424 → **40460**（+36） |
| RO-data | 1736（不变） |
| hex | 2647 行逐行校验 **0 错**，42304 数据字节，md5 **`1a7a903b48fc4bf5f2ac136a49a07fa5`** |
| map | `battery_get_level` 存在（0x08004669，大小 **0x6c = 108 字节**） |

### 3.2 ★ 反汇编铁证（最强形态 —— 阈值不再是电压）

`battery_get_level` 的实际指令里出现四个立即数，**正是设计值**，且旧电压值一个都不存在：

```asm
0x08004688:  MOVT r1,#0x4040   @..   → 0x40400000 =   3.0f   ; p <= 3  → lv 3
0x08004696:  MOVT r1,#0x4120   .. .  → 0x41200000 =  10.0f   ; p <= 10 → lv 2
0x080046a4:  MOVT r1,#0x41a0   .. .  → 0x41a00000 =  20.0f   ; p <= 20 → lv 1
0x080046b2:  MOVT r1,#0x41b8   ....  → 0x41b80000 =  23.0f   ; p <  23 保持(滞回)
```

- 每个比较前都是 `MOV r0,r4`（`r4` = 从 `g_filt_pct` 取出的值）后调 `__aeabi_fcmple/fcmplt` ⇒ **判的是百分比不是电压**
- `13.5f`(0x41580000) / `13.0f`(0x41500000) / `12.6f`(0x41496666) 在整个函数中**已不存在**
- 函数入口第一件事是 `LDR r0,[r5,#8]` 并与 `0.0f` 比较 = 读 `g_filt_pct` 的"尚未采样"守卫

> ⚠️ 本次**无法**用"镜像搜 GBK 文案"举证：`low_batt_poll` 的文案是 `"\xB5\xE7..."` 转义写法，AC6 用 MOVW/MOVT 逐字压栈，**不存连续字节**（对照：`hmi_push_device_info` 的"产品编号/固件版本"因是普通字面量可在 axf 中搜到）。这是**预期行为，非缺陷**。

### 3.3 滞回行为

| 当前档 | 升档（跌到） | 降档（回升到） |
|---|---|---|
| 0 正常 | ≤20% → 1 | — |
| 1 提示 | ≤10% → 2 | ≥**23%** → 0 |
| 2 警告 | ≤3% → 3 | ≥13% → 1 |
| 3 耗尽 | — | ≥6% → 2 |

## 4. 影响

| 项 | 说明 |
|---|---|
| 屏端 | **零改动** |
| 串口流量 | 不变（告警文案本就是"变化才发"） |
| 音效节奏 | 不变（`lv2` 每 30s、`lv3` 每 10s、进级即响一次） |
| 低电三级判据 | **不再依赖分压电阻/校准系数** ⇒ 换电池后告警时点自动跟随新曲线 |
| 换电池 | 阈值改成百分比后，**换电池只影响曲线表标定，不需再动阈值** |

## 5. 待真机验证（6 项）

1. ★ **放电到 20% 时应出现橙色「电量低请充电」**（v46 是 6% 才出现）
2. ★ **跌到 10% 应变红「电量低请更换电池」**
3. ★ **跌到 3% 应显示「电量将耗尽请立即充电」**（新文案）
4. **回升到 23% 才恢复"正常"**（滞回，不能在 20~23% 之间反复变色）
5. 无跳变 / 无超 100 / 无死机
6. 满电显示 100%

## 6. ⚠️ 关于「6% 时关机无法启动」

**这个现象不在本批修复范围内** —— 它是**电池衰减到寿命末期 + PCM 保护切断**的物理行为，任何软件改不动（见 `电量曲线修正方案_2026-10-08.md` §八）。

本批改的是**让告警在正确的时点出现**：以前用户看到 35% 才收到"请充电"提示，实际早已没电；现在 20% 就提醒 —— **给用户留出了 10% 的缓冲时间去充上电**。

**根治仍是换电池**。换完后按 §6 重新标定曲线；阈值本身不必再动。
