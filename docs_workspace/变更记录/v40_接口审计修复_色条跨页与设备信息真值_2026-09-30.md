## 2. 改动清单

### A. 报警色条 `dvr` 改为按页后缀下发（修 P1-1）

原实现（`app_refresh` 内）用硬编码对象名，只推主页那一份：

```c
/* 旧 */
if (full || stc != s_stc) { s_stc = stc; tjc_set_pco(OBJ_STRIP, stc); }   /* 恒为 "dvr" */
```

现**并入 `hmi_update_status_chips()`**（与探头/泵/电量圆点同源同门）：

```c
/* 新增档位缓存 + 参与提前返回判定 */
static uint32_t s_strip = 0xFFFFFFFFu;
uint32_t stc = (g_alarm >= 2) ? (uint32_t)C_STRIP_RED
             : (g_alarm == 1) ? (uint32_t)C_STRIP_ORANGE : (uint32_t)C_STRIP_GREEN;
if (!g_full_dirty && !full && dot == s_dot && pump == s_pump && bpic == s_bat && stc == s_strip) return;
...
snprintf(n, sizeof(n), "dvr%s", sfx);  tjc_set_pco(n, stc);   /* 主页/设置/历史/初始化 各一份 */
```

展开后正好命中屏端 4 个已有对象：`dvr`（主页）/ `dvr_s1` / `dvr_s2` / `dvr_i` —— **屏端无需任何改动**。
旧的主页硬编码推送已删除（`cc` 浓度大字颜色仍只主页，保持不变）。

### B. 设置页设备信息行推真实值（修 P1-2 / P1-3）

新增 `hmi_push_device_info()`（`main.c`），由 `app_refresh` 的**进页全量补发分支**调用（屏端进页按页面初值绘制，故每次进页都要重推）：

```c
static void hmi_push_device_info(void) {
  char b[48];
  snprintf(b, sizeof(b), "\xB9\xCC\xBC\xFE\xB0\xE6\xB1\xBE    %s", FW_VERSION_STR);   /* 固件版本    ... */
  tjc_set_txt(OBJ_FW_VER, b);
  snprintf(b, sizeof(b), "\xB2\xFA\xC6\xB7\xB1\xE0\xBA\xC5    %s", device_id_get()); /* 产品编号    ... */
  tjc_set_txt(OBJ_SN_STR, b);
}
```

- `FW_VERSION_STR = "V1.0.0-b40"`（产品版本 + 构建号，屏上版本字段可用 10 字符）—— 放在 `c4f7n_hmi_protocol.h`
- **SN 新增独立模块 `BSP/{Inc,Src}/device_id.c`**：
  - 存储位置 **STM32F103RCT6 内部 Flash 最后一页 `0x0803F800`（2KB）**，与 W25Q64 参数区/历史区完全独立
  - **首次上电**若无有效记录 → 用 MCU 96bit 唯一 ID 派生 `SN-C4F7N-XXXXXXXX` → 落盘（逐机唯一、产线零操作）
  - 之后上电只读；**"恢复出厂"不会清 SN**（出厂标识本就不该被恢复出厂重置）
  - 记录 32B：`magic(4) + sn[24] + xorv(4)`；按 16bit 半字编程
  - 选它而非 W25Q64 的原因：Q64 的 2048 扇区已全部分配（0=参数、1~2047=历史，历史用 `gen % HIST_SECTORS` 环形寻址），挪扇区会导致**已有历史记录的扇区映射错位**；而塞进 `param_t` 会触发 `PARAM_VERSION` 升级 → 首上电标定与阈值回默认

### C. 删除死路径 `0x18`，并**顺带修复"泵启动清零峰值"不可达**（修 P1-4 + 新发现）

- 删 `HMI_CMD_PUMP_TOG = 0x18`（enum）+ `case`（`hmi_callback.c`）+ `hmi_on_pump_toggle()` 定义与声明；命令位在注释里标注"空出，勿复用"
- ★ **实施中发现的连带漏洞**：`hmi_on_pump_toggle()` 里那段"泵启动清零峰值"（`g_peak = 0.0f; g_min = 4294967.0f;`）**因为 0x18 无屏端发射源，早已不可达** —— 这正是"重置峰值能力消失"的真正原因（`stats_reset()` 早先已删）。已把该逻辑**并入 `hmi_on_test_toggle()` 的 `if (g_test)` 分支**，即"开始测试（泵启动）时清零峰值/最小值"，行为恢复可达。
- `pump_toggle()` 作为 BSP 原子操作保留（不再被业务层调用）

### D. 协议头注释纠错（修 P1-5）

`c4f7n_hmi_protocol.h` 头部原写 `USART1 PA9(TX)/PA10(RX)`、配套 `C4F7N_HMI_v18.HMI`、`版本 v2` —— 已改为 `USART3 PB10/PB11`、`C4F7N_v8.HMI`、`v40`；`0x18` 处补了删除原因说明。
同时清理了 `OBJ_LOWBATT` / `HMI_AUDIO_ID` 的注释复制污染，新增 `OBJ_FW_VER "fw"` / `OBJ_SN_STR "sn"` 两个宏。
