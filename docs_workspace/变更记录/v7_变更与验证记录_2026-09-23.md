## 1. 需求

给按键添加按键音效。

## 2. 屏硬件前提（已核实）

官方规格书 **TJC1060X570_011R_I_G8**（X5 系列）：

| 项 | 值 |
|---|---|
| **喇叭** | **支持** —— 接插件 PH1.25×2，功率 ≤2W，官方注"需保证供电充足" |
| **蜂鸣器** | **不支持** —— 官方原文："可用喇叭搭配蜂鸣器素材实现" |

→ **`beep` 指令在本型号不可用**（仅带蜂鸣器的型号支持）。音频必须走 `play` + wav。
→ 用户已确认**真机已接喇叭，报警时能听到声音**，故按键音可实施。

## 3. 指令依据（官方 wiki）

```
play ch,audio,loop      /* 仅 X3/X5 系列支持 */
  ch   : 音频通道序号 0 或 1
  audio: 音频 ID（= wav 资源编号，即文件名数字）
  loop : 0 = 播放1次   1 = 循环
audio0 / audio1         /* 通道控制：0=停 1=播 2=暂停 */
```
- 音频播放**全局、不属于某页** → 跳页后继续播
- ⚠️ 官方警告：**用 `play` 后屏黑屏/重启 = 供电不足**

## 5. 改动内容（20 个控件，各加 1 行）

**每行统一为 `play 1,1,0`**：通道 **1** / ID **1** / 不循环。
用**通道 1** 的核心理由：通道 0 已被固件报警音占用，若混用会**互相打断**；分通道后两路可混音共存。

**插在 `down`（按下瞬间）事件** —— 反馈最即时；动作仍保留在 `up`，互不影响。

| 页 | 数量 | 控件 |
|---|---|---|
| `4.pa` 主页 | 5 | `nh` `ns` `nc` `ptg` `bm` |
| `5.pa` 设置 | 8 | `nh1` `ns1` `nc1` `c0` `c1` `cf` `hm` `hp` |
| `0.pa` 历史 | 6 | `nh2` `ns2` `nc2` `prst` `bup` `bdn` |
| `6.pa` 初始化 | 1 | `lg_i`（"跳过"热区，`type=112`） |
| **合计** | **20** | — |

**键盘页 `1.pa`（16 键）按决策排除** —— 敲击频繁易吵，且编辑器重存重建该页时这些行会丢。

| 页 | 字节 | 增量 |
|---|---|---|
| `4.pa` | 31 577 → 31 647 | +70（5×14） |
| `5.pa` | 74 447 → 74 559 | +112（8×14） |
| `0.pa` | 110 654 → 110 738 | +84（6×14） |
| `6.pa` | 21 117 → 21 131 | +14（1×14） |
| 合计 | — | **+280 B** |

> 每行开销 = **4 B 长度前缀 + 10 B 文本 = 14 B**（`play 1,1,0` 是 **10** 个字符）。
> 行内脚本仍远低于 16 字节误判线；`codesdown-0` → `codesdown-1` 声明改数字是**等长**的。

## 7. 风险与回退

| 风险 | 说明 | 回退 |
|---|---|---|
| **屏端脚本发 `play` 未经实测** | 官方文档只示范"通过串口下发"；样例中在按钮事件里写的是 `beep`（本型号不支持） | 若烧录后无声：改为按钮发新命令码（如 `0x19`）→ 固件收到后回发 `play 1,1,0`。需新增命令码 + 固件改动 + 重编 |
| **供电** | 官方明确警告 `play` 后黑屏/重启 = 供电不足；按键音触发比报警音频繁得多 | 换更大功率 5V 电源 |
| **音量不可调** | 蜂鸣器音量固定；喇叭音量可用 `volume` 系统变量调 | 调 `volume` 或替换 `1.wav` 素材（重做素材需在编辑器导入） |
| **连点节奏** | 阀值 ± 与翻页会连续发声 | 若嫌吵，删掉这 4 个控件的该行即可（改动局部） |

### 10.1 音频 ID 的来源已实证

`main.HMI` 资源表（offset 96 起，每条 16 B：8 B ext + 8 B name）中 **`wav` 条目的顺序即音频 ID**：

| 表内序号 | 资源 |
|---|---|
| ID 0 | `0.wav` |
| ID 1 | `1.wav` |
| ID 2 | `2.wav` |
| ID 3 | `3.wav` |
| **ID 4** | **`4.wav`** |

→ **音频 ID = 文件名数字**（与字库 `font=` id 同一机制）。此前只是设计推断（依据固件 `HMI_AUDIO_ID=3` 播 `3.wav`），本轮已由资源表**实证**。

🔧 校验工具：`node tjc-hmi-toolkit/C4F7N/_audio_id_check.js <HMI>`

### 10.2 两个按键音素材的客观对比

| 素材 | 采样率 | 时长 | data | 峰值 RMS | 波形特征 |
|---|---|---|---|---|---|
| `1.wav`（v7） | 22050 Hz | 50 ms | 2 208 B | 0.600 | 单次短脉冲 |
| **`4.wav`（v7b）** | **44100 Hz** | **27 ms** | 2 400 B | 0.612 | 单次极短脉冲（更干脆） |
