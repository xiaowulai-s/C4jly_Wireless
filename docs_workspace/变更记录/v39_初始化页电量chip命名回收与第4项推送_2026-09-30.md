## 3. 为什么屏包改名必须走编辑器（程序化改不可行）

核过 `tjc-hmi-toolkit/lib/stamp.js`，有两条硬约束：

1. **page 块携带内容 stamp**：`stamp = CRC32(块内容) ^ K(块长度)`，而 **`K` 是按块长度的离散常量表**（仅 31 个已知长度）。源码注释明写 *"Lengths outside this table cannot be stamped"*。`pc2`→`pc2_i` 会让 `6.pa` 长度 **+2**，大概率没有对应 K → 生成不出合法 stamp → 编辑器报 **Loading Page Failed**。
2. **目录 checksum 算法未解**：`stamp.js` 尾部明确 *"do not write the directory yourself. Let the Editor's library rebuild it"*。

⇒ 数据长度变化 ⇒ 目录 size 变化 ⇒ 无法自写。**只能走编辑器**（与 v8 同一流程）。
