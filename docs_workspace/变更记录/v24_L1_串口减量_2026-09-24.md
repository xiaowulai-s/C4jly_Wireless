## 1. 改动内容（仅 `Core/Src/main.c`，GBK/LF，+2131 B / 11 处）

| # | 位置 | 改动 |
|---|---|---|
| R1 | 153 行区 | 新增 3 个全局标志：`g_page_now`（固件视角当前页 0/1/2，0xFF=未知）、`g_full_dirty`（进页/上电全量补发）、`g_refill_req`（历史表补发请求） |
| R2 | `hmi_update_status_chips` 重写 | ① 签名加 `uint8_t full`；② 状态镜像缓存（探头圆点/泵/电量档），**未变且非 full → 零发送**；③ **按当前页只发那一套副本**（主页无后缀 / 设置 `_s1` / 历史 `_s2` / 初始化 `_i`）；④ **删除幽灵对象 `pc0_s3`/`pc1_s3`**（v7b 屏上不存在，原每轮白发 2 条）；⑤ 初始化页电量文本 `pc2_i` 整数变化才发 |
| R3 | 主页 mute/ptg 按钮 | 两态文本加缓存：状态不变不发，进页由 full 补发（覆盖"切页回默认文案"） |
| R4 | `refill_table` 门控 | 原：**任何页**每 2s 无条件 1749B。现：仅历史页（`g_page_now==2`）；触发 = `g_refill_req`（进页）/ 页码或 `history_total()` 变化（翻页·新记录）/ 5s 兜底；周期 2s→5s |
| R5 | `hmi_update_init_cover` | 修复死发送：`vis` 缓存真正用于门控，`"--"` 仅状态切换发一次（原每轮发，屏端对 type54 的 `.txt` 静默忽略） |
| R6 | 主页刷新块 | `cc.val`（实时量）保留每轮；`cma/cmn` 取整值缓存；`cc.pco`/`dvr.pco` 颜色缓存；主页探头/泵文本（pc0/pc1）并入 R2 按页分发 |
| R7 | `app_refresh` 开头 | 消费 `full = g_full_dirty`（读后清零，本轮所有镜像点无条件发一次） |
| R8 | `hmi_on_page_enter` | 记录 `g_page_now=p` + 置 `g_full_dirty=1`；**p==2 分支不再直接 `refill_table()`**（ISR 内阻塞发送 1749B，违背 fix12 约定）→ 改置 `g_refill_req` |
| R9 | `hmi_on_tbl_page` | 同上：直接 refill → 置 `g_refill_req`（翻页响应 ≤250ms） |
| R10 | `hmi_on_pump_toggle` | ISR 内直接刷圆点 → 置 `g_full_dirty`（下一轮全量补发，含峰值清零后的 cma/cmn） |
| R11 | `hmi_on_test_toggle` | 同上（ptg 文案 + 圆点交主循环） |

**保持不变**：预热倒计时（本就有整秒门控）；历史写入门控；标定/阈值链路。

## 4. 附：115200 波特率支持性检查（同日，未实施）

> ⚡ **后续（同日）：已实施为固件 v25，见 §4.1。**

- **官方支持列表**（wiki.tjc1688.com/qa/baudrate.html）：`2400 4800 9600 19200 38400 57600 **115200** 230400 256000 512000 921600` ✓
- **屏包**：`Program.s` 用会话级 `baud=9600`（非持久 `bauds`，不耗 flash）→ 提速时改这一行即可（9→11 字符，远低于 255 上限）
- **固件**：`usart.c:73`；同芯片 USART1 已跑 115200，时钟无压力
- ⚠️ **必须屏+固件同批升级**（屏上电即设新波特率，握手也是新速率；不同步则互相失联）
- 属设计方案 L3，暂缓；L1+L2 若已满足延迟指标则无需 L3

### §4.1 v25：波特率提速 9600 → 115200 已实施（2026-09-24）

- **源码**：`usart.c:73` `BaudRate = 9600 → 115200`（**用户在 Keil 里自行修改保存**，GBK/CRLF 保持；全仓仅此一处波特率代码，main.c 内 3 处 9600 为 L1 诊断历史注释，语境正确不改）
- **编译**：产物 axf/hex/map mtime 14:00:51（晚于源码 14:00:38），Code 大小不变（hex 104991 B）
- **产物级证据（逐字节 diff）**：v24 vs v25 展开镜像（134 255 056 B）**仅 2 字节差异** `16 52 → e1 32` @ **0x08003BAA** —— 该地址恰在 `MX_USART3_UART_Init`（map：0x08003B90+60B）函数体内，即波特率立即数指令；其余 134MB **逐字节相同**
- **产物**：`tjc-hmi-toolkit/C4F7N/C4F7N_v25_firmware.hex`（md5 `6cbfde22658113b2e67c86985c9ea872`；v24 为 `089da392...`）
- ⚠️ **烧录强约束**：屏包（`baud=115200`）与 v25 固件**必须同批生效** —— 只烧固件不烧屏（或反之）= 双方波特率不匹配，**完全失联**（屏无更新、触摸无响应）。屏端新 `.tft` 导出后一并烧录
