## 一、发现的根本缺口

取证屏端全部 `printh` 后发现：**页号通知不是页级 load 事件，而是点底部导航按钮时才发。**

| 页 | 资源 | 发页号的控件 |
|---|---|---|
| 主页 | `4.pa` | `nh`→`printh 40` / `ns`→`41` / `nc`→`42` |
| 历史曲线 | `0.pa` | `nh2`/`ns2`/`nc2` → 同上 |
| 设置 | `5.pa` | `nh1`/`ns1`/`nc1` → 同上 |
| 初始化 | `6.pa` | （无页号事件） |
| keybdB | `1.pa` | （无页号事件） |
| **厂家设置** | **`2.pa`** | **只有 `bk`（`page 2`），无导航按钮 → 不发任何页号** |

**后果链**：

```
厂家页不发页号
  → 固件 hmi_callback 的 switch 收不到 0x40~0x43
  → g_page_now 停在设置页(1)
  → sfx 恒为 "_s1"
  → 厂家页的 pc0_f / pc2_f / pc0d_f / pc1d_f / dvr_f / lb_f 永远收不到值
  → 顶栏胶囊与低电提示在厂家页不显示
```

★ 这类「协议缺口」**编译期不报错、结构校验也查不出**，
只有把屏端 `printh` 与固件命令码**逐条对照**才能发现。

`C4F7N/C4F7N_v9_p5.HMI`，仅改 `2.pa` 页对象的 `load` 事件，**首行插入 `printh 45`**：

```tjc
rY_f.val=rtc0
rM_f.val=rtc1
rD_f.val=rtc2
rH_f.val=rtc3
rMi_f.val=rtc4
rsec_f.val=rtc5
tm0.en=1
codesloadend-0
```

★ 放首行：屏端 `page` 类指令之后的代码不执行，`printh` 越早发越可靠。
★ `codesload-7` → `codesload-8` 已同步。

## 三、固件改动（4 处，已完成）

### 3.1 `Middleware/Inc/c4f7n_hmi_protocol.h`（UTF-8）

```c
  HMI_CMD_PAGE3_ENTER  = 0x43,
  /* [v60] 厂家设置页(页ID 5): 该页无底部导航, 页号由页对象 load 发 printh 45 通知 */
  HMI_CMD_PAGE5_ENTER  = 0x45
} hmi_cmd_t;
```

### 3.2 `Middleware/Src/hmi_callback.c`（UTF-8）

```c
    case HMI_CMD_PAGE3_ENTER:
    case HMI_CMD_PAGE5_ENTER:   /* [v60] 厂家页: 页对象 load 发 printh 45, 非导航按钮 */
      hmi_on_page_enter((int)b - (int)HMI_CMD_PAGE0_ENTER); break;
```

★ **无需改 `hmi_on_page_enter`** —— 它已统一置 `g_page_now = p; g_full_dirty = 1`，
且 `0x45 - 0x40 = 5` 天然等于页 ID。

### 3.3 `Core/Src/main.c`（**GBK**）—— sfx 门控 ×2

`hmi_update_status_chips()` 第 555 行：

```c
  else if (g_page_now == 2u) sfx = "_s2";
  else if (g_page_now == 5u) sfx = "_f";   /* [v60] 厂家设置页(页5): 顶栏胶囊副本 */
```

`low_batt_poll()` 第 664 行：

```c
  else if (g_page_now == 2u) sfx = "_s2";
  else if (g_page_now == 5u) sfx = "_f";   /* [v60] 厂家设置页(页5) */
  snprintf(n, sizeof(n), "lb%s", sfx);
```

⚠️ **`pc2_f`（电量胶囊）仍需下一轮处理**：不能照搬 `tjc_set_bat()` 的
「无条件推 4 条」—— 那招只对存在无条件推送路径的对象有效，
而 `pc2` 走 `sfx` 门控。本轮加了 sfx 分支后厂家页会开始收 `pc2_f`，
但 `tjc_set_bat()` 的第 4 项目前推的是 `pc2_i`（初始化页），需下一轮确认。
