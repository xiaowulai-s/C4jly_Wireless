## 1. 三处改动

### ① 屏 `keybdB / b210`：补回 `printh 11`

`b210`（OK 键）的 `codesup` 由 47 行改为 **48 行**，在 `page loadpageid.val` **之前**插入一行：

```
…                        第46行  }
printh 11                第47行  ← 新增：通知 MCU 回读 h.val
page loadpageid.val      第48行
```

**证据**：`hmipack` 报 `1.pa 25437B → 25450B`（+13 B = 4 B 长度前缀 + 9 B 文本）；
`hmi_audit_check` 在 v5 上复扫 → `printh 11 : ✓ keybdB/b210.up`。

### ② 屏 `设置 / 5.pa`：`h.key` 2 → 4

`h.key` 的语义 = **键盘页的页面 ID**；按新页序 keybdB = **4**（旧值 2 会弹到设置页自己）。

**证据**：`5.pa` 与基线**逐字节比对仅 1 处差异**（offset 8519，`0x02 → 0x04`）。

### ③ `Program.s`：注释 `(页面ID=4)` → `(页面ID=3)`

同尺寸单字节替换（offset 597，`0x34 '4'` → `0x33 '3'`），文件尺寸 642 B 不变。
语句 `page 3` / `printh 00 00 00 ff ff ff 88 ff ff ff` / `baud=9600` / `recmod=0` 全部逐字节未动。

### ④ 固件 `main.c`：`tjc_page(4)` → `tjc_page(3)` ×3

开机进初始化页的三次调用（L348 / L351 / L353）按新页序改为 **3**；
同时把 6 处注释里的「页4」改为「页3」（等长替换，**GBK 字节数完全不变：43031 → 43031**）。
`tjc_page(0)`（预热结束回主页）保持不变 ✓。
