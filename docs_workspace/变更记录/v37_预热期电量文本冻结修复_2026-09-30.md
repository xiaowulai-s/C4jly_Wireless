## 1. 现象

| 阶段 | 显示 | 实际 |
|---|---|---|
| 预热期（初始化页） | 约 5 秒内"不连续递加"到 **50%**，随后 55 秒**不动** | 真实电量已 65% |
| 进主页后 | **65%**，持续稳定 | 65%（真实值） |
| 万用表量主控板电池端子 | 两状态**无区别** | 电压确实没变 |

## 2. 根因（**不是测量问题，是推送被冻结**）

`Core/Src/main.c::hmi_update_status_chips()` —— 初始化页电量文本 `pc2_i` 的推送块**位于「圆点档位缓存」提前返回之后**：

```c
461  uint8_t bpic = (pct >= BAT_DOT_WARN_PCT) ? (uint8_t)PIC_DOT_GREEN
462               : (pct >= BAT_DOT_LOW_PCT)  ? (uint8_t)PIC_DOT_AMBER : (uint8_t)PIC_DOT_RED;
     /*  BAT_DOT_WARN_PCT = 50 ; BAT_DOT_LOW_PCT = 20   (c4f7n_hmi_protocol.h:96-97) */
463  if (!g_full_dirty && !full && dot == s_dot && pump == s_pump && bpic == s_bat) return;   /* ← 档位不变即返回 */
...
479  if (g_page_init) {                          /* ← 在提前返回之后, 到不了 */
481    if (full || pct != s_pct) { ... tjc_set_txt(OBJ_BAT_CHIP_I, ...) ... }
485  }
```

**`bpic` 是「三档圆点颜色」，不是 pct。** 预热期 pct 从 ~30% 爬到 65% 的全程里，`bpic` **只在 pct 跨过 50 那一瞬变一次**：

- pct 跨 50 → `bpic` 橙→绿 → 不 return → 执行到 484 行 → `pc2_i` 被写成「**电量 50%**」
- pct 继续 50→65 → `bpic` 恒为绿 → 每轮在 463 行 return → **`pc2_i` 永久冻结在 50%**

**"冻结值恰好等于 50" 就是指纹** —— 50 正是绿档阈值。

**为什么主页是对的**：主页 chip `pc2`（及 `pc2_s1`/`pc2_s2`）由 `battery.c` 的 `battery_poll()` 经 `tjc_set_bat()` **每 250ms 无条件推送** → 显示真实值。

**回归来源**：**L1 改造（v24 / 2026-09-24）引入** —— L1 之前 chips 每轮无条件全发，`pc2_i` 实时跟随；L1 引入"变化才发"镜像缓存后，这个块被套在了**不相关**的圆点档位缓存之后。

**曾走过的弯路（记录以免重蹈）**：先怀疑 VDDA 随负载漂移（v36 每轮重测 VDDA），真机复测**症状依旧**；且用户实测两态端子电压无区别，直接否定了测量侧假说。**教训：两个显示位置不一致时，先比对"推送路径差异"，不要先怀疑测量链** —— 值源相同 ≠ 推送时机相同。

## 3. 修复（`main.c`，GBK/LF，`_fw_v37_pctfix.js`）

改动 3 处（脚本用**行号定位 + 逐行内容断言**，全部通过后才写盘）：

1. 函数级新增 `static int s_pct = -1;`（原来藏在块作用域里，位于提前返回之后）
2. `pc2_i` 推送块**前移**到提前返回**之前**，并给它**自己的门** `(full || pct != s_pct)`
3. 删除原位于提前返回之后的那份块

```c
static void hmi_update_status_chips(uint8_t full) {
  static uint8_t s_dot = 0xFFu, s_pump = 0xFFu, s_bat = 0xFFu;
  static int     s_pct = -1;         /* 初始化页电量文本缓存: 独立于下面的圆点档位缓存(v37) */
  ...
  /* [bugfix 2026-09-30 v37] 初始化页电量文本: 必须有自己的门(pct 变化), 不能落在下面那个
   * 「圆点档位缓存」提前返回之后 -- bpic 只在跨 20/50 时变, 50% 以上不再触发, ... */
  if (g_page_init && (full || pct != s_pct)) {
    char cb[24];
    s_pct = pct;
    snprintf(cb, sizeof(cb), "\xB5\xE7\xC1\xBF %d%%", pct); tjc_set_txt(OBJ_BAT_CHIP_I, cb); }
  if (!g_full_dirty && !full && dot == s_dot && pump == s_pump && bpic == s_bat) return;
  ...（圆点/探头/泵文本段原样不动）
}
```

**串口成本**：`pc2_i` 仅在 pct 整数变化时发 1 条，稳态 0 条 → **不破坏 L1 减量目标**。
**语义安全**：`g_page_init` 守卫保留；`g_page_init` 只 1→0 不回升，`s_pct` 无残留问题；圆点/文本段与缓存条件全部未动。
