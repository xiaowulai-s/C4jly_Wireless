# v48 变更与验证记录：低电提示进页补发 + 多页下发

> 2026-10-08。上序：v47 低电三级改按电量百分比（`v47_低电三级改按电量百分比_2026-10-08.md`）。
> 本批修 v47 真机验证暴露的两个问题：**「进主页后不显示低电文字」** + 「只有主页能显示」。

## 1. 触发：v47 真机日志（14:18:34~54）

日志中固件**确实发了**三条指令（`14:18:38.916`）：

```
lb.pco=62689          ← 橙色 = lv1 ✓
lb.txt="???????????"  ← 10 字节 = 「电量低请充电」GBK ✓
play 1,5,0            ← 低电音 ✓
```

但**屏上什么都看不到**（只听到声音）。两个原因，逐个查实：

### 1.1 `lb` 只存在于主页 —— 发到初始化页被静默忽略

实测（`_pc2_owners.js /^lb/`）：**全工程只有主页 `4.pa` 有 `lb`**，其余三页都没有。

日志同时证明当时屏在**初始化页**：`pt0_i` 倒计时 60→59→…→44，且所有对象都带 `_i` 后缀（`pc2_i` / `pc0_i` / `dvr_i` …）。

⇒ `lb.txt=` 发到初始化页 → 屏端**找不到对象、静默忽略**（TJC 标准行为，不报错）。
⇒ 而 `play` 是**全局指令**与页面无关 → 造成「**有声无字**」的错觉。

> 记忆里 `main.c` 对这行的注释写的是「低电三级提示(lb+音效): **全页有效**」—— 这句是**不准确的**，已一并更正。

### 1.2 ★ 切页后 `low_batt_poll()` 不会重发文案（真正的直接原因）

屏端切页会按**页面存储的初值**重绘控件，而主页 `lb` 的初值是**空串**（实测 `rawlen=0`）。

而 `low_batt_poll()` 原逻辑：

```c
if (lv == s_lv) {          /* 电平未变化 */
    if (lv==2 && >=30s) || (lv==3 && >=10s)) tjc_lowbatt_play();
    return;                /* ★ 直接 return, 不重发文案 */
}
```

⇒ 进主页时 `lv` 没变（还是 1），走上面分支**只重播音效、不重发文案** ⇒ `lb` 永远是空。

**★ 这是 v38 同族缺陷的第 4 例**（`hmi_update_status_chips` 第 470 行判据里有 `g_full_dirty` 参与能穿透，`low_batt_poll` 没有）。

## 5. 设计说明：为什么用 `sfx` 而不是逐页 if

与 v39（电量 chip 4 副本）/ v42（色条 `dvr%s`）**完全同一套机制**，已真机验证过两次：

```c
sfx = "_s1";                                /* 未定页(0xFF)兜底, 防漏发 */
if      (g_page_init)      sfx = "_i";
else if (g_page_now == 0u) sfx = "";
else if (g_page_now == 2u) sfx = "_s2";
snprintf(n, sizeof(n), "lb%s", sfx);
```

> ⚠️ **注意**：`sfx` 的兜底是 `_s1`（设置页）—— 因为 `g_page_now` 初值 `0xFF` 表示"未知"，此时发设置页副本，与 `hmi_update_status_chips` 一致。

### 6.2 ★ `lv3`（≤3%）在真机上从未出现

原因（本次已量化）：6% 对应端子 **13.35V = 3.34V/节**，而本机电池**内阻达正常新品数倍**（同日实测：静置 16% / 带载 3%），**带载压降使实际端电压跌破 PCM 过放阈值** → 切断。

⇒ **`lv3` 对当前这块衰减电池是"不可达档位"**；**换电池后**（内阻正常，带载 6% 仍有约 1.5~2.5V 缓冲）**才会出现**。不是代码缺陷。

