## 2. T-13 泵 PWM（v28，真机闭环）

**接线考证**（KLVP1 手册 p5 电机控制页 + 新原理图 09-28 版）：
- KLVP1-E-SB 为 **4 线制**（红 Vcc / 黑 GND / 蓝白 PWM / 黄 FG），**无使能线** —— 启停由 PWM 占空比实现（**0~10% 不转，11~100% 调速**）
- **PWM = PB6 = TIM4_CH1**（无 remap 默认映射，与 `pump.c` 预填配置吻合）；电平转换由硬件 **AO3401A** 实现（输出 5V PWM 至 CN4，用户确认）—— 软件侧无需电平处理
- **FG 首版不接**（`PUMP_HAS_FG=0`，转速显示暂缺，`pump_get_rpm_ff()` 返回 -1）；`PUMP_HAS_CTL` 永不启用

**固件改动**：
- `pump.c`：`PUMP_HAS_PWM=1`；新增 `pump_pwm_hw_init()` —— PB6 复用推挽 + TIM4 时基（72MHz/3600=**20kHz**，ARR=3599）+ PWM1 高有效 + **上电 CCR=0（停转，命中 0~10% 区）**；CCR 换算改 ARR 基；修正从未定义过的占位宏 `PUMP_PWM_TIM_CHANNEL_1`
- `stm32f1xx_hal_conf.h` 启用 `HAL_TIM_MODULE_ENABLED`；`.uvprojx` 加 `stm32f1xx_hal_tim.c` + **`hal_tim_ex.c`**（必须成对，否则 L6218E 链接错）
- **手写 TIM4 init 不走 CubeMX**（混合编码工程禁止重生成）—— `.ioc` 不登记 TIM4，`pump.c` 注释注明唯一真源

**调试迭代**：19E（htim4 未定义）→ 12E（HAL API 全要指针，宏改 `(&htim4)`、点改箭头）→ 2E（ConfigChannel/Start 多余取址）→ **0E/0W**。

**真机**：「开始测试/停止测试」可控泵启停 ✅（2026-09-28）。占空比恒 100%（`pump_set_duty` 无调用方），流量 ≈1.0 L/min（手册曲线，随背压降）。

## 3. T-09 低电三级（v30）

| 级别 | 触发（1s 防抖 + 0.3V 回升滞回） | `lb` 文案 | 音效（id=5，通道 1，避开报警音通道 0） |
|---|---|---|---|
| 正常 | >13.5V | 空白 | 无 |
| 提示 | ≤13.5V（3.38V/节） | 橙 62689「电量低，请充电」 | 进入播一次 |
| 警告 | ≤13.0V（3.25V/节） | 红 59944「电量即将耗尽」 | 每 30s 重播 |
| 耗尽前 | ≤12.6V（3.15V/节） | 红 | **每 10s 重播** |

- **EN 使能脚未接 MCU** → 无自动断电能力，3 级 = 持续催促模式；`BAT_SHUTDOWN_V` 预留，硬件补 EN 线后可升级真关机
- 正常使用电量**最低到 ~14%**（12.6V），不会显示 0%，不进 3.0V/节过放损伤区
- 协议新增 `SCREEN_VAR_LOWBATT`/`HMI_CMD_PLAY`；`tjc_cmd` 新增 `tjc_play()`；文案 `\xNN` 转义（0 警告）

## 4. 电量显示链路三修（v31/v32/v33）+ 基准（v29）

| 版本 | 问题 | 根因 | 修法 |
|---|---|---|---|

| v32 | 满电卡 99% 到不了 100 | 升格需滤波值 >shown+1.1=**100.1**，但原始 pct 钳位上限 100，**永远达不到** | 满电特判：`pct>=100 && g_filt_pct>99.5 → shown=100`（降回仍需 <98.9，不交替） |
