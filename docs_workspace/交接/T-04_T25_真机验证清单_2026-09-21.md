## 5. D 组 · 标定与恢复出厂（T-05）

> 标定判据用**当前显示浓度**（已含旧 k/b 校准）。零点标定需洁净空气（<20ppm）；量程标定需通入 1000ppm±10% 标气（`SENSOR_SPAN_PPM=1000`）。无标气时 D2/D3 只验"失败路径"，成功路径待标气。

| # | 操作 | 预期 |
|---|---|---|
| D1 | 洁净空气（读数 <20ppm）点零点标定 | 按钮文本变"执行"（成功）；读数应归 0 附近 |
| D2 | 点零点标定（读数 ≥20ppm，如对探头呼气） | 按钮文本变"失败"，参数不变 |
| D3 | 通 1000ppm 标气点量程标定 | 读数在 900~1100 内 → "执行"；斜率写入并落盘 |
| D4 | 无标气（读数不在 900~1100）点量程标定 | "失败"，参数不变 |
| D5 | 标定后断电重启 | 标定系数保持（cal_k/cal_b 落盘） |
| D6 | 恢复出厂第一步 | 屏端弹确认（`cfs/cft` 双步，不会一点就清） |
| D7 | 确认第二步 | 参数恢复默认 + 120ms 后自动复位，重新走页 6 预热流程 |
| D8 | 恢复出厂后检查 | 阈值回默认、标定清（cal_valid=0）、蜂鸣开关回默认 |

### 11.1 已知会「看起来像故障」的现状（**不是 bug**）

- **首次上电参数回默认值**：`PARAM_VERSION` 2→3，标定系数与阈值（500/100）都会回默认，需重设一次 —— 版本迁移的必然代价
- **「重置峰值」按钮没有了**：历史页 `prst` 已改为「清空历史」；主页「最大值 / 最小值」现只在**泵启动**时清零
- **低报不发声**：固件 `g_alarm >= 2` 才挂报警音，低报（=1）只有色条与文字
- **`0.wav` / `2.wav` 从不播放**：它们是当年设计的分级报警素材（慢速间歇 / 连续长鸣），固件只用 `3.wav` 一级
