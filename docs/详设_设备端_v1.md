## 一、双 MCU 分工架构（既定原则：业务全在 STM32）

```
[传感器 GC5G1]──ADC──┐                      ┌──[蜂鸣/报警灯]
[按键]───────────────┤                      ├──[泵 MOS]
[电池/充电]──────────┤   STM32F103RCT6      │
                     │  · 采集/滤波/补偿     ├──[W25Q64 参数区]   ← 阈值/标定/补偿
[ESP32-S3 网桥]──UART┤  · 1Hz 业务状态机     ├──[W25Q64 历史区]   ← 1Hz 环形落盘
   (BLE/USB-CDC)  2  │  · 报警自治           ├──[内部Flash 末页]  ← SN+认证哈希+激活
                     │  · 协议 v1.1 分发     └──[预留 RS485 总线]
```

- **ESP32-S3 = 通信协处理器**：只做 BLE/USB-CDC ↔ UART 字节透传（按 A5 5A 切帧），不含业务逻辑；重启/断连不影响检测与报警。
- **STM32 = 业务主机**：全部业务状态机、参数持久化、历史记录、报警自治、协议应答。
- **屏版退役**：TJC 屏与 hmi 模块从无线版固件剔除；屏版仓库冻结、仅做存量 bug 修复。

## 四、安全与量产清单

1. 量产前必做：`WL_FACTORY_AUTH_BYPASS=0`；产测流程（PC）固化"烧写认证哈希"步骤；
2. `PRODUCT_SN_FORCE_WRITE` 保持 0（防产线误覆盖 SN）；
3. 标定参数防提取（F8）：wireless.c param_read 对 calK/calB/manK/manB 在非厂家会话下返回 NACK 0x03；
4. Flash 页预算：0x0803F800 页 = SN(32B) + 认证哈希(0x40 起 48B) + 激活记录(0x80 起 24B) —— 同页共管，任何写入必须整页重写并保留其余记录（`device_id.c` 已实现该模式）。
