## 1. 帧格式

```
偏移   0      1      2      3      4 .. 3+N      4+N     5+N
     +------+------+------+------+-------------+--------+--------+
     | 0xA5 | 0x5A | LEN  | CMD  |   PAYLOAD   | CRC_L  | CRC_H  |
     +------+------+------+------+-------------+--------+--------+
```

| 字段 | 长度 | 说明 |
|---|---|---|
| 帧头 | 2 B | 固定 `A5 5A` |
| LEN | 1 B | CMD + PAYLOAD 字节数（不含帧头/CRC），≤ 240 |
| CMD | 1 B | §3 命令表 |
| PAYLOAD | 0~239 B | **一律小端序**；多字节整数低字节在前；f32 = IEEE754 单精度小端；字符串 = GBK 定长，余位填 0；保留字段填 0 |
| CRC | 2 B | CRC16-MODBUS（poly=0x8005 初值 0xFFFF，结果低字节在前），计算范围 = CMD+PAYLOAD |

## 2. 链路与时序

| 项 | 值 |
|---|---|
| 载荷传输 | BLE：单帧 = 一次 Write/Notify（MTU 协商 ≥247，帧 ≤240B 不分片）；USB-CDC：帧流直通 |
| 请求-响应 | App→设备命令必须回 ACK（同 CMD 回显）/NACK（payload 1B 错误码）；App 超时 2s 重试 1 次；同一时刻仅 1 条未应答命令 |
| 心跳 | App 每 5s 发 0x01；设备 15s 无帧 → 判 App 离线（BLE 图标灭 + 静音自动解除） |
| 重连 | ESP32 断开后 200ms 内恢复广播；App 自动重连（指数退避 1s→2s→4s→…上限 30s） |
| 实时上报 | 设备 1Hz 主动发 0x10，无需应答 |

### NACK 错误码（payload[0]）

| 值 | 含义 |
|---|---|
| 0x01 | CRC 校验失败 |
| 0x02 | CMD 未知 |
| 0x03 | 权限不足（需厂家令牌） |
| 0x04 | 参数值越界 |
| 0x05 | 设备忙（请稍后重试） |
| 0x06 | 存储异常 |
| 0x07 | 帧长度非法 |
| 0x81 | （仅 0x31）需要二次确认（随 ACK 语义，非错误） |

## 4. 命令 payload 详细定义

### 4.1 CMD 0x01 心跳/握手

```
App→设备（4B）
  u32 proto_ver        // = 0x00000100（v1.0）
设备→App（12B）
  u32 proto_ver
  u8  battery          // 0~100
  u8  device_state     // bit0 泵运行 bit1 报警中 bit2 静音 bit3 历史满告警 bit4 参数区失效(param_reset_flag)
  u8  fw_major         // PRODUCT_FW_VERSION 主版本
  u8  fw_minor
  u8  param_ver        // = PARAM_VERSION (4)
  u8  reserved[4]      // 填 0
```

### 4.2 CMD 0x10 实时数据上报（设备→App，1Hz，16B）

```
  u16 conc_x10         // 浓度 ppm×10（12.4ppm → 124）
  u16 temp_x10         // 传感器温度 ℃×10
  u16 peak_x10         // 本次开机峰值 ppm×10
  u8  battery
  u8  device_state     // 同 §4.1
  u16 thr_hi_x10       // 当前报警阈值 ppm×10（镜像 param.thr_hi）
  u32 uptime_s
```

### 4.3 CMD 0x11/0x12 参数读/写（param_id 全表，对齐 param_store v4）

```
0x11 App→设备（2B）   u16 param_id
0x11 设备→App（6B）   u16 param_id + u32 value
0x12 App→设备（6B）   u16 param_id + u32 value
0x12 设备→App（6B）   u16 param_id + u32 value（回读值；失败回 NACK 0x04/0x03）
```

| param_id | 名称 | 类型/单位 | 对应 param_store 字段 | 范围 | 默认 |
|---|---|---|---|---|---|
| 0x0001 | 报警阈值 | u16, ppm | `thr_hi` | 1~6000 | 500 |
| 0x0002 | 低报警阈值（占位，固件不启用） | u16, ppm | `thr_lo` | — | 0 |
| 0x0003 | 标定斜率 k | i32, 0.001 倍 | `cal_k` | ± | 1000 |
| 0x0004 | 标定偏移 b | i32, ppm | `cal_b` | ± | 0 |
| 0x0005 | 手动零点补偿 | i32, ppm | `man_b` | -200~200 | 0（=未设定） |
| 0x0006 | 手动斜率补偿 | i32, 千分比 | `man_k` | 100~10000 | 0（=未设定） |
| 0x0007 | 蜂鸣器使能 | u8 | `buzzer_en` | 0/1 | 1 |
| 0x0008 | 设备编号（广播名后缀） | u16, hex | （新增至 param 或 device_id） | 0x0000~0xFFFF | 出厂定 |
| 0x0009 | 历史起算代数（只读） | u32 | `hist_base` | — | — |
| 0x000A | 标定时间戳（只读） | u32, epoch | `cal_ts` | — | 0 |
| 0x000B | 零点标定原始值（只读） | i32 | `cal_raw0` | — | 0x7FFFFFFF=未标定 |

规则：0x0003~0x0006 写入需厂家令牌（对齐屏版权限）；0x0009/0x000A/0x000B 只读（写入回 NACK 0x03）。

### 4.4 CMD 0x20 泵控制 / 0x21 静音

```
0x20 App→设备（1B）  u8 on        // 1=开泵 0=关泵
0x20 设备→App（1B）  u8 state     // 回显当前实际状态
0x21 App→设备（1B）  u8 mute      // 1=静音 0=恢复
0x21 设备→App（1B）  u8 state
```

注：App 离线（15s 无心跳）后设备自动解除静音，恢复本地报警。

### 4.5 CMD 0x30 零点校准（两步确认，对齐现有固件流程）

```
Step1  App→设备（1B）  u8 step=1
Step1  设备→App（8B）  u16 conc_x10     // 当前读数
                       u16 stable       // 1=读数已稳定可校准 0=不稳定
                       u32 reserved
Step2  App→设备（1B）  u8 step=2
Step2  设备→App（1B）  u8 result        // ACK: 1=成功 / NACK: 0x05 读数不稳 0x06 传感器异常
```

成功后设备更新 `cal_raw0`、`cal_ts` 并 `param_save`。

### 4.6 CMD 0x31 厂家标定/补偿（需厂家令牌）

```
App→设备（9B）
  u8  op               // 0x01=斜率标定 0x02=截距标定 0x03=写补偿b 0x04=写补偿k 0x05=恢复出厂参数
  u8  confirm          // 首次=0；收到 0x81 后重发并置 1
  f32 value            // op=03/04 时有效；其余填 0
设备→App（2B）
  u8  result           // ACK: 1=已生效 0x81=需二次确认（值变更>20%）/ NACK 错误码
  u8  reserved
```

恢复出厂（op=05）：**保留历史数据**（对齐 `param_factory` 语义：只清参数与标定，不动 hist_base）。

### 4.7 CMD 0x40 历史数据读 / 0x41 删除

设备端现状（history.h）：6B 记录 = u32 时间戳（秒，**大端存于 Flash**）+ u16 ppm；环形容量 2046×682 = 1,395,372 点；按"从最旧数第 idx 个"寻址。

```
0x40 App→设备（6B）
  u32 start_idx        // 从最旧数第几个点（0 起）
  u16 max_n            // 本批最多条数 ≤ 32
0x40 设备→App（每帧 1+6×n B）
  u8  n                // 本帧条数
  ×n 组（每条 6B，转为本协议小端）：
    u32 ts             // 时间戳（秒）
    u16 ppm
  末帧 n=0 表示结束；若请求范围越过最新点，按实际可用条数返回
0x41 App→设备（1B）   u8 confirm=0xAA
0x41 设备→App（0B）   ACK（纯 ACK 帧，无 payload）
```

删除语义 = `history_clear()` 逻辑清空（推进 hist_base，不擦物理扇区）。

### 4.8 CMD 0x50 自检

```
App→设备（0B）
设备→App（8B）
  u32 result_bits      // bit0 传感器 bit1 存储 bit2 泵 bit3 电池采样 bit4 OLED bit5 BLE链路；1=正常
  u8  err_code[4]      // 各失败项首个错误码（正常填 0）
```

### 4.9 CMD 0x60 事件上报（设备→App 主动，8B）

```
  u8  event_id         // 1=报警开始 2=报警结束 3=低电 4=BLE恢复 5=历史满 6=泵异常 7=MCU链路异常
  u8  reserved[3]
  u32 timestamp_s      // 设备 RTC epoch；RTC 未同步时为开机秒（App 端据 0x01 心跳对齐判断）
```

### 4.10 CMD 0x7A 厂家认证

```
App→设备（20B）
  u8  digest[16]       // = SHA-256("C4F7N-FACTORY-" + 口令 + "-" + 设备SN) 前 16 字节
                       // 设备 SN = 设备编号 u16 的 4 位十六进制大写字符串
  u8  reserved[4]
设备→App（1B）
  u8  result           // 1=认证通过（会话开启）/ 0x03=认证失败
```

- 会话随 BLE 断开或 15s 无心跳自动失效；
- 连续失败 5 次 → 设备锁定 300s（期间 0x7A 一律回 0x03）；
- 口令不出现在任何 App/PC 包内（由售后人员人工输入）。

## 5. BLE GATT 定义（冻结）

| 项 | 值 |
|---|---|
| Service UUID | `48B5C976-CAE8-4BA4-9D6C-F560D9958777` |
| 特征：命令写（App→设备） | `48B5C976-CAE8-4BA5-9D6C-F560D9958777`，Write Without Response |
| 特征：数据通知（设备→App） | `48B5C976-CAE8-4BA6-9D6C-F560D9958777`，Notify |
| 广播名 | `C4F7N-XXXX`（XXXX = 设备编号 4 位十六进制大写） |
| 广播间隔 | 100~200 ms |
| 连接参数 | interval 30~50ms，latency 0，supervision timeout 2s |
| MTU | 协商 ≥ 247 |
| 安全模式 | 无配对绑定；权限靠 §4.10 会话令牌 |

## 6. 实现核对清单（三方各自对照）

- [ ] STM32 `wireless.c`：帧收发状态机、CRC16-MODBUS、本表逐命令 handler、param_id 映射 param_t、0x40 映射 history_read_one、0x7A 令牌状态机
- [ ] ESP32 `uart_bridge.c`：仅按 `A5 5A + LEN` 切帧透传，**不解析 CMD**
- [ ] App/PC `protocol` 模块：编解码与本表逐字段一致（含小端序、f32、GBK 字符串）；CRC 算法与设备端互验（用本表测试向量）
- [ ] 模拟器 `sim/`：实现 0x01/0x10/0x11/0x12/0x20/0x21/0x30/0x40/0x60 最小集

## 7. 测试向量（三方互验用，必测，CRC 已实算）

```
帧1：泵开（0x20, on=1）
  HEX: A5 5A 02 20 01 D9 B0
帧2：阈值读（0x11, param_id=0x0001）
  HEX: A5 5A 03 11 01 00 20 55
帧3：实时上报（0x10：conc=124(12.4ppm) temp=263 peak=182 bat=86 state=0x01 thr=500 uptime=120s）
  HEX: A5 5A 0F 10 7C 00 07 01 B6 00 56 01 F4 01 78 00 00 00 9E F2
帧4：心跳响应（0x01：ver=0x00000100(LE:00 01 00 00) bat=86 state=0x03 fw=4.10 paramver=4）
  HEX: A5 5A 0E 01 00 01 00 00 56 03 04 0A 04 00 00 00 00 75 1F
帧5：静音恢复（0x21, mute=0）
  HEX: A5 5A 02 21 00 19 E0
```

> CRC 计算范围 = CMD+PAYLOAD，结果低字节在前（小端）。例：帧1 CMD+payload=`20 01` → CRC=0xD9B0 → 帧尾 `D9 B0`。

## v1.1 变更（2026-11-15，无线版维护命令）

### 0x00 维护命令族（payload[0] = 子操作）

| 子操作 | 说明 | 请求 payload | 响应 payload | 权限 |
|---|---|---|---|---|
| 0x01 SN 读取 | 读设备 SN（ASCII） | [0x01] | [0x01, ...SN ASCII] | 免会话 |
| 0x02 SN 写入 | 烧写新 SN（8~24 可打印 ASCII） | [0x02, ...SN] | [1] | 厂家会话 |
| 0x03 认证哈希烧写 | 烧写 SHA-256(口令)，与 SN 同页重写（互不覆盖） | [0x03, ...32B] | [1] | 厂家会话 |

### 0x7A 厂家认证（v1.1 变更）

- 请求 payload：**SHA-256(口令) 全 32 字节**（旧版 16B 含 SN 的摘要作废）；
- 设备比对烧写的哈希：一致 → [1] 开会话；未烧写 → NACK 0x03；不一致 → [0]；
- 桌面联调期设备固件保持 `WL_FACTORY_AUTH_BYPASS=1`（接受任意），烧写哈希后可置 0 收紧。

### Rust 实现对齐

`pc/src-tauri/src/protocol.rs` 与 Dart `packages/c4f7n_protocol` 使用同一组冻结测试向量（CRC "123456789"=0x4B37、泵帧 A5 5A 02 20 01 D9 B0、阈值读帧 A5 5A 03 11 01 00 20 55），双端测试全过。
