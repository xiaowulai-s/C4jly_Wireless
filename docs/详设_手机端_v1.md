## 一、应用结构（已实现）

```
app/lib
├── main_user.dart / main_factory.dart     # flavor 入口
├── core/
│   ├── device_source.dart                 # 数据源抽象：Mock / Ble（切换零成本）
│   ├── protocol/（packages/c4f7n_protocol）
│   └── permissions
├── data/
│   ├── db.dart        # SQLite v2：tasks / events / devices(收藏)
│   ├── report.dart    # PDF 报告 + Excel 导出 + 汇总统计
│   └── alarm_notify.dart                  # 报警系统通知
├── state/device_controller.dart           # 唯一业务控制器（ChangeNotifier）
└── ui/
    ├── app.dart                           # 导航壳 + 主题 + 引导
    └── pages/ measure / task(含汇总) / connect / settings / events / history / factory / guide
```

**设计原则**：
1. **设备自治镜像**：App 不保存任何设备参数真相——泵/静音/阈值状态一律以设备 ACK 回显为准；
2. **Mock/Ble 等价**：所有功能在 Mock 数据源下可完整演示（外部客户上手、销售演示零硬件）；
3. **单控制器**：DeviceController 集中持有链路/采样/任务/事件状态，页面只订阅。

## 三、本轮新增功能设计（⬜ → 落地规格）

### 1. 维护页（F1）
- 位置：设置页新增"设备维护"卡片；
- 数据：param 0x000C~0x0010（运行小时/报警次数/泵小时/传感器小时/电池健康）；
- 交互：各项进度条（阈值 param 0x0016+ 可配）→ 超阈值黄色提示 + 本地通知；
- 依赖：设备端 param v1.2（见设备端详设 §二）。

### 2. 泄漏点地图/台账（F3）
- 任务表 v3 迁移：新增 `geo_lat REAL, geo_lng REAL, pipe_section TEXT`；
- 测量页"开始任务"时请求定位（权限引导，拒绝则留空）；
- 新增"地图页"：第一代用任务列表按位置分组 + 系统地图应用跳转（免 SDK 合规）；第二代接地图 SDK 呈现漏点聚合；
- 报告 PDF 自动附位置。

### 3. 授权/激活（F5）
- 启动时读 param 0x0014/0x0015 → 试用中显示剩余天数横幅；
- 激活流程：设置页"设备激活" → 输入激活码（SN 绑定离线校验：code = f(SN, 内置密钥)）→ 经 0x00 维护族新子操作 0x04 写入（厂家逻辑上放 L1 但算法校验）；
- 试用到期：不影响测量，仅关闭报告导出（商业策略可调）。

### 4. 云同步抽象层（F6 接口预留）
```dart
abstract class SyncAdapter {
  Future<void> pushTasks(List<TaskRow> rows);      // 幂等：按 id+sn
  Future<void> pushEvents(List<EventRow> rows);
  Future<FwVersionInfo> checkFirmware(String sn);   // OTA 元信息
  Future<ActivationInfo> checkActivation(String sn);
}
class NullSyncAdapter implements SyncAdapter { ... }  // 第一代空实现
```
- DeviceController 持有 `SyncAdapter`，任务/事件落库后异步调用（失败静默重试队列）；
- 云端选型后只换实现类，业务代码零改动。

### 5. 上手体系（F7）
- 引导页 ✅ → 增补：演示模式开关（设备页显著入口）+ "连接失败自查"折叠卡（复用 PC 端排查表）+ 售后联系入口（电话/微信按钮，CONFIG 配置）+ FAQ 静态页。

## 四、技术债与注意事项

1. **BLE 单连接互斥**：手机连着时 PC 连不上（反之亦然）——UI 已提示；后续可在 App 增加"连接占用检测"（扫描时若设备不在广播则提示"设备可能被其他端连接"）；
2. **前台服务功耗**：真机观察电池消耗，必要时提供"仅前台监测"开关；
3. **数据库迁移**：v2→v3（geo 字段）沿用 onUpgrade 模式；
4. **factory flavor 的厂家口令**：现仍为输入式（BYPASS 期），量产前 App 与设备哈希联动（0x00/0x03 已就绪）；
5. **Windows/Mac 桌面版 Flutter**：如未来需要"桌面用户版"，Flutter 技术栈可直接复用（但产测工具已用 Tauri，不重复建设）。
