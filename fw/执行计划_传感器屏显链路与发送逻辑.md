# 执行计划 · 传感器→串口屏显示链路 与 屏对象发送逻辑

> 日期：2026-09-15
> 目标：让 C4 传感器(UART4) 的浓度数据正确解析后，经**串口屏所在的 USART**显示到屏上；并把屏对象发送逻辑的已知问题修完。
> 硬件前提（用户确认）：**串口屏 = USART3**，**C4 传感器 = UART4**。

---

## 一、链路核查结论（现状）

数据链路（`C4F7N_Demo` 当前代码）：

```
C4(UART4, PC11/9600)
  → sensor_init 原始寄存器接收
  → UART4_IRQHandler → sensor_uart4_irq_handler → feed_byte → parse_frame("xxx ppm")
  → g_ppm_now → main.app_refresh → sensor_read_ppm()
  → tjc_set_*(OBJ_CONC ...) → tjc_send_raw
  → HAL_UART_Transmit(&huart1)   <-- 目前走 USART1(PA9/PA10)
  → 串口屏
```

**关键差异：** 代码里屏数据发往 **USART1(huart1)**，而你确认屏在 **USART3**。
- 若屏物理接在 USART3(PB10/11)，则当前链路 **发错口**，屏收不到 → 必须把 tjc 发送迁移到 USART3(huart3)。
- UART4(C4 传感器) 部分已按原始寄存器方案就绪，无改动。

**已核查通过的部分：**
- 屏对象：MCU 实际使用的 `cc/pv/ba/ps/p9/pf/pt/et/eh/cma/cmn/ald/thv/u/pu/bb/c0/c1/h/l/…` 在 v93 屏工程均存在（`pth/pvr` 无此项但代码未使用，无影响）。
- `OBJ_CONC=cc` 为 num(vvs=2)，`cc.val=浓度*100` 显示正确。
